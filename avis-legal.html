2. Objecte

Aquest lloc web té com a finalitat donar a conèixer els serveis de construcció i reforma que ofereix el titular, mostrar treballs realitzats i facilitar el contacte amb persones interessades a demanar un pressupost.

3. Condicions d'ús

L'accés a aquest lloc web és gratuït i implica acceptar aquest avís legal. L'usuari es compromet a fer-ne un ús adequat i a no utilitzar-lo per a activitats il·lícites, ni per introduir virus o qualsevol element que pugui danyar el lloc web o els seus sistemes.

El titular es reserva el dret de modificar els continguts del lloc web, així com de restringir-hi l'accés temporalment per tasques de manteniment.

4. Propietat intel·lectual i industrial

Els textos, el disseny, el logotip, les fotografies i la resta de continguts del lloc web són propietat del titular o de tercers que n'han autoritzat l'ús. Queda prohibida la reproducció, distribució o transformació sense autorització expressa i per escrit.

Algunes imatges d'aquest lloc web procedeixen de bancs d'imatges amb llicència d'ús lliure.

5. Responsabilitat

El titular no es fa responsable dels danys derivats d'un ús inadequat del lloc web, ni de les interrupcions del servei alienes a la seva voluntat. La informació sobre serveis i terminis té caràcter orientatiu: qualsevol compromís concret queda recollit al pressupost signat amb el client.

Aquest lloc web pot contenir enllaços a pàgines de tercers, com xarxes socials o WhatsApp. El titular no es fa responsable dels continguts ni de les polítiques de privacitat d'aquests llocs.

Aquest avís legal es regeix per la legislació espanyola. Per a qualsevol controvèrsia, les parts se sotmeten als jutjats i tribunals del domicili del titular, llevat que la normativa de consumidors estableixi un altre fur.
